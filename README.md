### Game Design
Game design involves creating the world, characters, and storylines for a game. It includes concept art, level planning, character creation, dialogue, and overall game mechanics.
### Engine Development
Engine development is the process of creating and maintaining a game engine that powers the game. This includes programming languages, graphics APIs, physics engines, sound systems, and other components of the game framework.
