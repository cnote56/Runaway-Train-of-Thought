BLOG FORMATTING

When you log in, go to “Posts” >> “Add New”

There are a number of categories to select both to the right of the main content section and beneath the main content section. Follow the instructions below carefully to avoid any errors when publishing.

Blog Titles:

Try and keep titles relatively short since they can run too long on the current version of the playbook:

Ex: “Remembering Amar’e as a Knick”

Ex: “Deadline Deals: 5 NBA Trades that Won’t Happen”

Entry Fields to the RIGHT:

a.       Categories – Select the following - All Sports, Daily Research, Home Slider, NBA (or applicable sport)

b.      Tags – Leave blank

c.       Post Template – FULL WIDTH if it’s a longer article. DEFAULT TEMPLATE is fine if it’s shorter

d.      Featured Image – Select an image, see instructions below for downloading images

Entry Fields BENEATH Body Text:

a.       Link to add – Leave blank

b.      Time Offer – Leave blank

c.       Text Ad – Leave blank

d.      Loop_Categories – ALL SPORTS

e.      Show Category Name – “NBA” (or abbreviation for applicable sport)

f.        Submenu Name – Leave blank

g.       Image Post – Leave blank

h.      Title Slider – Copy and paste title from the top (keep titles short)

i.         Excerpt slider – First 40 characters or so from your intro or a brief one sentence description of the piece

j.        Revolution Slider Options – Default

k.       Text Control – Up to you. Allows you to pick a text formatting service if you are familiar with any in particular.
